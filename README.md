# dementia node

## English

This repository contains the installer and agent for AmneziaWG servers managed by dementia. The agent applies client configurations and reports connection and traffic data to the backend. [Full installation guide](https://github.com/dementia-panel#english)

## Русский

Здесь находятся установщик и агент для серверов AmneziaWG под управлением dementia. Агент применяет настройки клиентов и отправляет в backend данные о подключениях и трафике. [Полная инструкция по установке](https://github.com/dementia-panel#русский)
